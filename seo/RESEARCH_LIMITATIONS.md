# TehNet SEO Research Limitations

**Observation date:** 2026-09-15  
**Market:** Iran / Persian

## Evidence policy
TehNet follows the evidence hierarchy in `DashSaman/-SEO`: official/standard sources for engine behavior, measured observations for live site/SERP facts, and practitioner/community material only for discovery or examples.

No ranking claim is converted into a guarantee. No third-party metric is treated as a Google score.

## Ahrefs Iran limitation
The connected Ahrefs Keyword Explorer API was tested with country `IR` on 2026-09-15. The API rejected `IR`; Iran is not present in the endpoint's supported country list.

Therefore TehNet must **not** publish or internally invent Iran-specific Ahrefs search Volume, Traffic Potential, CPC or KD values for this research phase.

If a future data source provides real Iran search-demand data, it must be recorded with source, date and scope before being used for prioritization.

## What we can measure now
- Current Persian web/SERP result composition and dominant page type.
- TehNet's live technical state and HTTP/rendering behavior.
- Competitor page structure, offers and visible differentiation.
- Business value based on TehNet's real products/services.
- Search Console impressions/clicks/queries after indexing is deliberately enabled.

## What we cannot claim now
- Exact Iran monthly search Volume.
- Exact Iran keyword difficulty/KD.
- Exact national rank based on one search context.
- A probability that a URL will reach Page 1/Top 10.
- Local-pack rank for all Tehran searchers from a single observation.
