# TehNet SERP / Competitive Reality Map

**Observation date:** 2026-08-31  
**Language/market intent:** Persian / Iran  
**Status:** representative live web-search observations; **not an exact Google-Iran position report**.

## Measurement limitation

The connected Ahrefs SERP endpoint does not support country code `IR`, so exact Ahrefs Iran SERP positions cannot be reported. This document therefore records dated public-web observations and visible competitor/page patterns. Never convert the list order below into a claimed Google ranking position.

A future TehNet rank-tracking baseline should use Google Search Console after launch plus a provider/location setup that can actually measure Iranian/Persian SERPs.

## Cluster 1 — generic MikroTik education

Representative observed pages/brands:

- `modir-shabake.com` — homepage and current MTCNA 2025 course. Strong roadmap framing, multiple network tracks, practical/real-network positioning, current-vs-legacy handling.
- `mikrotikuniversity.net` — dedicated MikroTik education brand with articles/books/download center/courses/demo.
- `fanamoozan.com/course/mikrotik-training/` — long-form commercial training page with multi-level MikroTik curriculum, hours, fees and consultation CTA.
- YouTube: House of MikroTik Iran / Fallahzadeh / Tosinso content surfaces around MTCNA and learning-roadmap demand.

### SERP/page-type inference

Generic education intent is mixed but heavily favors **topic/roadmap hubs and course landing pages**, supplemented by YouTube. A thin blog post should not own `آموزش میکروتیک`.

### TehNet decision

`/learn/mikrotik/` owns generic MikroTik learning/roadmap intent and routes users to free tutorials, labs and paid courses. Individual certifications/courses live separately; do not create another generic `/tutorials/mikrotik/` page that competes with the learning hub.

## Cluster 2 — MikroTik / network services

Representative observed pages/brands:

- `emdadshabake.ir` — broad network-support company covering MikroTik, Cisco, FortiGate, HP servers, VMware, VoIP/Issabel, VPN, virtualization, backup and infrastructure.
- `iranhelpdesk.com` — network support with a visible request→remote diagnosis→on-site dispatch→report/prevention process and MikroTik specialization.
- `itamoz.ir` — network/server support, project options including MikroTik/security and server/ESXi, plus recent troubleshooting educational content and quote-like interaction.
- `varianet.ir` — network/security/IT support, monthly support packaging, training and declared Tehran/Alborz coverage.
- `aristec.net` — dedicated MikroTik service copy around firewall, VPN, bandwidth control, DHCP, load balancing and related RouterOS features.

### SERP/page-type inference

Commercial service intent expects a **real company/service landing page** with scope, process, availability, proof, contact/quote flow and often location/service-area context.

### TehNet decision

- `/services/` = service hub.
- `/services/network-support/` = generic managed/support intent.
- `/services/mikrotik/` = MikroTik implementation/config/support.
- `/services/vpn/` = VPN/tunnel implementation.
- separate pages for Linux/server, VoIP, firewall/security and virtualization only when each has real scope/evidence.
- no fake city pages; state nationwide remote + Tehran/nearby on-site availability honestly.

## Cluster 3 — network equipment / MikroTik purchase

Representative observed pages/brands:

- `itshabake.com` — broad network/server store with Cisco, HPE, MikroTik, Legrand, Nexans, Huawei, UniFi etc.; category content and wholesale angle.
- `mrshabake.com/product-brands/mikrotik/` — dedicated MikroTik category, trust/price/shipping/consultation cues and physical address/contact.
- `pasargadtech.ir/category/network-equipment` — network-equipment category with visible MikroTik models/prices plus category explanatory copy.
- `shop.netnety.net` and `tabinahayat.com` — equipment catalog/category/product commerce patterns.

### SERP/page-type inference

Commercial-buying intent expects **inventory-bearing category/product pages**, prices/availability where known, trust/fulfilment information and useful filters. Informational copy alone is insufficient.

### TehNet decision

- `/shop/` = shop department/root.
- a stable MikroTik category (final WooCommerce category permalink configured once) owns generic buy-MikroTik intent.
- product model pages own exact model/SKU intent.
- category pages contain concise selection context and links to genuine guides, not keyword-stuffed essays.
- `inquiry` items remain visible but clearly say price/availability requires inquiry; never show invented stock.

## Cluster 4 — network learning roadmap / Cisco/Linux

Representative observations:

- `modir-shabake.com` actively uses learning-roadmap architecture spanning Cisco, Microsoft, Linux, security, firewall, monitoring, backup and virtualization.
- Tosinso YouTube content explicitly answers “where to start” across networking, Cisco, Microsoft, Linux, virtualization, MikroTik and security.
- `rayka-co.ir` groups educational products by Cisco, CompTIA, MikroTik, Linux, Microsoft, programming and VMware.

### TehNet decision

Create topic hubs rather than flat tag archives:

- `/learn/linux/`
- `/learn/cisco/`
- `/learn/voip/`
- `/learn/ai-networking/`

Each hub must have a user journey/roadmap and real child assets before indexation.

## Cluster 5 — applied AI for network administrators

Current Persian search observations did not reveal a dominant specialized TehNet-like competitor page set comparable to MikroTik/service/ecommerce clusters. Results are fragmented/general.

### TehNet decision

Treat this as an **emerging experimental cluster**, not proven mass commercial demand. Start with genuinely useful project content such as:

- AI-assisted log triage with privacy/safety constraints;
- network config review assistant with human validation;
- monitoring alert summarization;
- AI helpdesk triage;
- troubleshooting workflows where commands/evidence are verified.

Measure engagement/query data before expanding into a large programmatic cluster.

## Competitive lessons to use — not clone

1. **Roadmaps work:** competitors make “where do I start?” explicit.
2. **Freshness matters in networking:** legacy RouterOS courses are explicitly redirected/reframed toward newer versions.
3. **Commercial service pages need process:** not just a list of technologies.
4. **Equipment pages need commerce facts:** real price/stock/fulfilment and model-level data.
5. **Education + real scenario evidence is a stronger differentiator than syllabus length alone.**
6. TehNet's opportunity is connecting all four business lines contextually rather than becoming four disconnected sites.
