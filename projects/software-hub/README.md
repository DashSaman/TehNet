# آرشیو نرم‌افزار تهران نتورک

**تصمیم فعلی مالک:** فایل دانلودی روی دیسک وب‌سایت ذخیره نمی‌شود؛ دانلود از میرورها و فضای بیرونی خواهد بود. [راهنمای ذخیره‌سازی](EXTERNAL_STORAGE.md)، [راه‌اندازی رمز روی سرور](deployment/ENGINE_OPERATIONS.md) و [وضعیت واقعی کار](STATUS.md) را بخوانید. موتور جدید روی `/software` فعال است؛ بکاپ، بازیابی و بازگشت نسخه آزموده شده‌اند. رمز را مالک روی سرور تعیین می‌کند؛ دانلود خصوصی و روبیکا هنوز تأیید نشده‌اند. [مدرک فعال‌سازی](evidence/ENGINE_ACTIVATION.md).

این بخش از **تهران نتورک** است؛ نام محصول مستقلی ندارد. مسیر عمومی `/software/` و پوشه توسعه `projects/software-hub/` است. نام مخزن مبدأ فقط برای حفظ منشأ پژوهش در اسناد تاریخی باقی می‌ماند.

بخش عمومی فعال است: https://tehnet.ir/software/ .

**به‌روزرسانی خودکار آفلاین فعال شد:** بررسی هر ۶ ساعت و ساخت نسخه تازه پس از ۱۲ ساعت از آزمون موفق؛ انتشار فقط پس از امضای معتبر، هش کامل و نصب پاک با آزمون هشت ابزار. محدودیت ۴۸ ساعت ابزار دریافت حفظ شده است. [نتیجه واقعی و خطاهای ثبت‌شده](evidence/AUTO_REFRESH.md)، [زمان‌بندی، سهمیه و بازیابی](deployment/AUTO_REFRESH.md). فایل‌های نرم‌افزار همچنان بیرونی‌اند؛ اختلال طولانی میرور می‌تواند دریافت امن را متوقف کند.

[انتخاب منبع و فرمان کپی‌پیست](https://tehnet.ir/software/offline/sources/)، [نتیجه هر تلاش، از جمله خطای اولیه و اصلاح LinuxMirrors](evidence/PROVIDER_KITS.md)، [روش آماده‌سازی و بازگشت](deployment/PROVIDER_KITS.md). این تأیید برای کیت مشخص و تاریخ آزمون است؛ فایل‌ها مستقیم از منبع بیرونی دریافت می‌شوند.

## وضعیت فعلی

- **W0 نهایی شد:** قرارداد نسخه ۱، مدل‌های مشخص، تفکیک عمومی/محدود، دیتابیس نسخه‌دار، اتصال فقط‌خواندنی و پشتیبان‌گیری صحیح SQLite؛ ۹ آزمون قرارداد پاس شد.
- **نسخه اولیه عمومی پیاده‌سازی شد:** نمای فارسی واکنش‌گرا، جست‌وجو، ۲۷ ردیف منبع پژوهشی، API عمومی، وضعیت آمادگی و پروفایل پیشنهادی Ubuntu. این ردیف‌ها میرور تأییدشده یا اپراتورهای مستقل شمرده نمی‌شوند.
- **رنگ و راهنمای نصب:** مطابق رنگ‌های روشن/تیره و فونت سایت؛ ۸ راهنمای نصب آنلاین با توضیح، کپی فرمان و بررسی نتیجه. این راهنماها به معنی نصب آفلاین آزموده‌شده نیستند.
- **۱۱ فایل دانلود عمومی مشخص پذیرفته شده‌اند؛ ۲۷ ردیف پژوهش تأیید کلی نشده‌اند.** بررسی کامل دوره‌ای همین فایل‌های پین‌شده هر ۳۰ دقیقه انجام می‌شود. احراز هویت مستقر است، ولی تا انتخاب رمز مالک مسیرهای خصوصی بسته می‌مانند؛ دانلود خصوصی بیرونی جداگانه تأیید نشده و هیچ داده خصوصی VPN وارد نشده است.
- ۲۲ فایل اصلی پژوهش با هش و انتساب حفظ شده‌اند. کاتالوگ اصلی OFFLINE_SOFTWARE_CATALOG همچنان در دسترس نیست؛ طبق دستور مالک، توسعه با پژوهش موجود ادامه دارد و منتظر آن نمی‌ماند.
- وضعیت فعلی در [گزارش دانلود واقعی](evidence/CATALOG_EXPANSION.md)، [فعال‌سازی موتور](evidence/ENGINE_ACTIVATION.md) و [STATUS](STATUS.md) ثبت می‌شود؛ [گزارش استقرار اولیه](evidence/DEPLOYMENT.md) تاریخی است. آزمون محلی یا بسته‌بندی، به‌تنهایی ادعای استقرار نیست.

## اجرای توسعه

از همین پوشه، Python 3.12 و وابستگی‌های نسخه‌بندی‌شده لازم‌اند. `requirements.lock` شامل wheelهای Linux amd64 با هش دقیق است؛ روی Windows از محیط توسعه سازگار استفاده کنید و نتایج را با تصویر Linux نیز تکرار کنید.

برای محیط توسعه Linux amd64 با Python 3.12، فرمان‌های زیر را به ترتیب اجرا کنید. مرحله نصب وابستگی‌ها به دسترسی PyPI نیاز دارد؛ اجرای نسخه بسته‌بندی‌شده با wheelهای آماده بدون دانلود انجام شده است. محیط آزمایش از وابستگی‌های اضافه استفاده می‌کند که داخل تصویر سرویس نصب نمی‌شوند.

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install --require-hashes -r requirements-dev.lock
python -m app.cli init-db
python -m app.cli seed-public-research
python -m uvicorn app.main:app --host 127.0.0.1 --port 18783
```

صفحه را در `http://127.0.0.1:18783/software/` باز کنید. برای آزمون‌ها در ترمینال دیگری با همان محیط فعال:

```bash
python -m unittest discover -s tests -v
```

داده محلی در `data/` و خارج Git نگه‌داری می‌شود. برنامه HTTP دیتابیس را ایجاد/مهاجرت نمی‌کند؛ عملیات مدیر صریح و محلی است. آزمون‌های استقرار Linux روی Windows skip می‌شوند و باید روی Linux اجرا شوند. فایل‌های پژوهش، داده، backup و secrets هیچ‌وقت web root نیستند.

## تعهدهای حفظ‌شده

سایت WordPress، قالب، افزونه Core، فروشگاه و مسیرهای موجود بازنویسی نمی‌شوند. تغییر مجاز این مرحله فقط بخش مستقل `/software/` و یک گزینه منو است. روبیکا غیرفعال می‌ماند. redirect مقصد را آشکار می‌کند؛ تعرفه داخلی، نصب آفلاین و مهاجرت واقعی زیر ۳۰ دقیقه تنها با آزمون مربوط پذیرفته می‌شوند.
