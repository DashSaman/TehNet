# آرشیو نرم‌افزار تهران نتورک — مرجع پژوهش و اجرای مستقل در TehNet

**از همین فایل شروع کنید.** این پوشه برای آرشیو نرم‌افزار تهران نتورک و زیرمسیر پیشنهادی `https://tehnet.ir/software/` است. کد، قالب، افزونه و تنظیمات فعال سایت تغییر نکرده‌اند. اسناد برای بررسی و شروع پیاده‌سازی آماده‌اند؛ خود سرویس هنوز ساخته یا مستقر نشده است.

## الان واقعاً چه داریم؟

- تمام ۲۲ فایل موجود `Linux/` از مخزن `DashSaman/software` با محتوای دقیق و شناسنامه SHA-256 کپی شده‌اند؛ اصل فایل‌ها باقی است.
- **کاتالوگ `OFFLINE_SOFTWARE_CATALOG` هنوز در دسترس نیست.** گفت‌وگوی قبلی می‌گوید ZIP/patch تحویل شده و روی GitHub منتشر نشده بود. [جزئیات و راه ورود امن](research/OFFLINE_SOFTWARE_CATALOG/README.md).
- طراحی، تقسیم کار و دستور مهاجرت نوشته شده‌اند. ابزار تمرین با داده مصنوعی موجود است؛ نتیجه واقعی آن در [گزارش بررسی](evidence/VALIDATION.md) ثبت می‌شود.
- نصب آفلاین واقعی، دسترسی داخل ایران، ذخیره‌سازی روبیکا، احراز هویت VPN و مهاجرت واقعی هنوز تأیید نشده‌اند. هدف زیر ۳۰ دقیقه، مشروط و نیازمند اندازه‌گیری روی دو سرور است.

## اصول محصول

بخش‌های معمول عمومی و فارسی هستند. بخش VPN فقط پس از احراز هویت سمت سرور دیده می‌شود؛ رمز جاوااسکریپتی، حذف لینک و robots.txt محافظت محسوب نمی‌شوند. داده خصوصی، رمز و توکن در Git عمومی قرار نمی‌گیرد.

آرشیو نرم‌افزار تهران نتورک ابتدا از میرورهای موجود و منابع مجاز استفاده می‌کند و فقط شکاف‌ها و نسخه‌های حیاتی را نگه می‌دارد. لینک اولیه دانلود از دامنه خودمان است؛ **redirect آدرس مقصد را آشکار می‌کند و تضمین ناشناس‌ماندن IP مبدأ نیست**. میزبانی واقعی فایل و تعرفه داخلی باید جدا اثبات شوند.

روبیکا فعلاً غیرفعال است. سرویس حرفه‌ای، پژوهش دانش‌بنیان، حمایت مالی، ثبت ملی و تعرفه داخلی هدف‌های بعدی با مدارک مستقل هستند؛ هیچ‌کدام در این تحویل اخذ یا تضمین نشده‌اند.

**قدم بعدی:** بازیابی ZIP/patch کاتالوگ؛ هم‌زمان مالک یکپارچه‌سازی می‌تواند قراردادهای مرحله W0 را نهایی کند. پیاده‌سازی، فعال‌سازی بخش خصوصی و تغییر Nginx فقط پس از گذر از دروازه‌های مستند همان مرحله.
