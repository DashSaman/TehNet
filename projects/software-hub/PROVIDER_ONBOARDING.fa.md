# اتصال ارائه‌دهنده‌های ذخیرهٔ ایرانی (آروان/ایرانسرور و مشابه) — نقشهٔ راه الزامی

**تصمیم مالک، ۲۵ اکتبر ۲۰۲۶:** آرشیو نرم‌افزار قرار است از ارائه‌دهنده‌های ایرانی (آروان، ایرانسرور و سایت‌های مشابه) به‌عنوان ارائه‌دهندهٔ خارجی (external) استفاده کند. این سند همان مسیر الزامی `EXTERNAL_STORAGE.md` و `CONTRACTS.md` را برای این ارائه‌دهنده‌ها دقیق می‌کند؛ هیچ قاعده‌ای لغو نشده است.

## وضعیت فعلی مرتبط

- پایلوت پذیرفته‌شدهٔ سه فایل عمومی روی **MobinHost/Arvan** از ۲۰۲۶-۱۰-۱۸ فعال است (`evidence/LIVE_MIRRORS.md`).
- موتور W3 (netguard/budget/TLS) و `ExternalRegistry` با گارد کامل پیاده شده‌اند؛ ثبت هر فایل فقط با `register-external` پس از تأیید کامل شبکه انجام می‌شود.
- Rubika فقط بررسی API شده و غیرفعال است (توکن مالک موجود نیست).

## برای هر ارائه‌دهندهٔ جدید، پیش از هر ثبت

۱. **تأیید اپراتور و مجوز توزیع** — مجوز کتبی اپراتور برای میزبانی/توزیع همان فایل‌ها + مدرک اتصال داخلی (داخلی‌بودن = `domestic_state=verified`).
۲. **دایجست معتبر مستقل** — SHA-256 و حجم کامل از منبع رسمی/مستقل؛ دایجستِ فقط از پاسخ همان ارائه‌دهنده هرگز کافی نیست.
۳. **فایل پالیسی خصوصی بیرون از Git** — دقیقاً با فیلدهای `SourceConfig` در `app/models.py`:
   `permission_state=approved`، `domestic_state=verified`، `approval_evidence` غیرخالی، `base_url` فقط HTTPS، `allowed_hosts` دقیق و محدود. `routing_enabled` پیش‌فرض false و `visibility` پیش‌فرض restricted است.
۴. **ثبت با CLI** در محیط موتور آماده‌شده (متغیرهای `TEHNET_SOFTWARE_DATA/METADATA/OPS` روی دایرکتوری‌های جدا):
   `python -m app.cli register-external --source-policy ... --sha256 ... --size ... --visibility public --license-approved --provenance ...`
۵. **محدودیت‌های فنی که عمداً fail-closed هستند** — حداکثر حجم تک‌فایل ۵۱۲MiB، مهلت تأیید ۱۰ ثانیه، سقف روزانهٔ درخواست/بایت. فایل بزرگ‌تر یا کندتر رد می‌شود؛ دور زدن این سقف‌ها بدون تصمیم نسخه‌دار ممنوع است.

## ورودی‌های لازم از مالک (بدون این‌ها ثبت ممکن نیست)

- کلید/توکن API شیء-استوریج آروان (S3-سازگار) یا دسترسی فضای ایرانسرور + انتخاب باکت/ناحیه.
- مجوز/قرارداد توزیع برای هر فایلی که باید روی آن‌ها منتشر شود.
- تأیید اینکه آروان «Object Storage» است یا آروان‌CDN؛ برای ایرانسرور مشخص شود سرویس دقیق (میزبانی فایل/میرور قراردادی).

## آنچه ساخته/تست شده و چه چیزی نه

- آماده: مسیر ثبت، گاردهای W3، پالیسی‌قالب، این سند.
- انجام‌نشده (عمداً): هیچ ارائه‌دهندهٔ جدیدی ثبت/فعال نشده؛ بدون مدارک بالا انجام‌پذیر نیست و نباید انجام شود.
