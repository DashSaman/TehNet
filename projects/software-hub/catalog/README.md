# دانلودهای عمومی تهران نتورک

[فهرست زنده](https://tehnet.ir/software/#downloads) اکنون ۱۱ فایل دارد: هشت ابزار زیر از میرور عمومی ابر آروان، دو Mini rootfs آلپاین از مبین‌هاست و بسته نمونه GNU hello. فایل‌ها فقط روی میرور هستند؛ سایت فقط مشخصات و لینک دقیق را نگه می‌دارد.

| ابزار | نسخه دقیق | معماری | بایت |
|---|---|---|---:|
| Git version control | `1:2.43.0-1ubuntu7.3` | amd64 | 3679758 |
| curl HTTP/TLS client | `8.5.0-2ubuntu10.15` | amd64 | 226504 |
| jq JSON command line | `1.7.1-3ubuntu0.24.04.2` | amd64 | 65694 |
| Python 3.12 minimal interpreter | `3.12.3-1ubuntu0.17` | amd64 | 2334634 |
| Python pip package manager | `24.0+dfsg-1ubuntu1.3` | all | 1319940 |
| GNU Wget downloader | `1.21.4-1ubuntu4.5` | amd64 | 334118 |
| rsync file synchronization | `3.2.7-1ubuntu1.5` | amd64 | 442954 |
| OpenSSH client | `1:9.6p1-3ubuntu13.19` | amd64 | 907922 |

بسته‌های جدول برای Ubuntu 24.04 هستند. Python minimal یک مفسر حداقلی است؛ pip برای دریافت کتابخانه‌ها به مخزن بسته نیاز دارد. این فایل‌ها شامل همه وابستگی‌ها نیستند و نصب آفلاین آن‌ها پذیرفته نشده است. روی توزیع یا نسخه دیگر نصبشان نکنید. روت‌فایل‌سیستم Alpine برای container/chroot است، نه ISO نصب.

## دریافت و بررسی ساده در سیستم خودتان

از کارت ابزار در سایت «دریافت» را انتخاب کنید، سپس فرمان بررسی هش همان کارت را کپی و در پوشه دانلود اجرا کنید. نتیجه باید `OK` باشد. نمونه زیر فقط jq را روی **سیستم کاربر** دریافت می‌کند؛ هیچ دانلودی روی دیسک سایت انجام نمی‌شود:

```sh
curl --fail --location --proto '=https' --proto-redir '=https' --tlsv1.2 \
  --output 'jq_1.7.1-3ubuntu0.24.04.2_amd64.deb' \
  'https://tehnet.ir/software/download/f59183392f84fe67b407b494d8ba6185e9b0e4a106ffcb369490bd20a83fd40e/jq_1.7.1-3ubuntu0.24.04.2_amd64.deb' &&
printf '%s  %s\n' 'f59183392f84fe67b407b494d8ba6185e9b0e4a106ffcb369490bd20a83fd40e' 'jq_1.7.1-3ubuntu0.24.04.2_amd64.deb' | sha256sum --check - &&
sudo apt install ./jq_1.7.1-3ubuntu0.24.04.2_amd64.deb
```

پیش از تأیید نصب، فهرست تغییرات APT را بخوانید. APT وابستگی‌ها را از مخازن پیکربندی‌شده سیستم شما می‌گیرد؛ دسترسی آنلاین یا مخزن آماده لازم است. دانلود کامل و هش این بسته واقعاً آزموده شده‌اند؛ نصب روی محیط پاک هنوز آزموده نشده است. برای نصب آنلاین آخرین نسخه سازگار با سیستم، راهنمای کپی‌پست فعلی سایت همچنان از مخازن پیکربندی‌شده استفاده می‌کند.

## نگهداری فهرست

[پین‌های دقیق](public-downloads.json) مرجع اپراتور هستند. هش/اندازه از صفحه رسمی Ubuntu و checksum رسمی Alpine آمده؛ مجوز و منشأ مستقل ثبت شده‌اند. لینک مستقیم مقصد را آشکار می‌کند. HTTPS و هش کامل بررسی می‌شوند؛ زنجیره امضای بومی APT/APK هنوز دروازه جداگانه W4 است. کشور ثبتی/ANYCAST اثبات تعرفه داخلی یا دسترسی هنگام قطع اینترنت نیست.

اضافه‌کردن فایل نیازمند بررسی منبع، نسخه، معماری، اندازه، هش و مجوز، آزمون کامل میرور، سنجش بودجه، به‌روزرسانی اتمیک و ثبت نتیجه است. کش/ذخیره فایل، ثبت URL عمومی دلخواه یا fallback خودکار وجود ندارد.
