# نصب آفلاین ابزارهای لینوکس — تهران نتورک

این راهنما مخصوص **Ubuntu 24.04 amd64** است. پروفایل `noble-devtools-amd64` شامل Git، curl، jq، Python 3.12، pip، wget، rsync و OpenSSH Client و پشتیبانی گواهی TLS است. نسخه نخست **۵۸ بسته، ۳۲٬۱۳۹٬۷۵۶ بایت** داشت؛ [پروفایل ذخیره‌شده](profiles/noble-devtools-amd64/manifest.json) و [گزارش نخست](evidence/OFFLINE_DEVTOOLS.md) شواهد همان نسخه‌اند. نسخه جاری، تعداد بسته‌ها، تاریخ و نتیجه آزمون آن را در [راهنمای سایت](https://tehnet.ir/software/offline/) ببینید. [وضعیت به‌روزرسانی خودکار](evidence/AUTO_REFRESH.md) و [راهنمای اپراتور](deployment/AUTO_REFRESH.md) جدا ثبت می‌شوند.

فایل‌های نرم‌افزار مستقیماً از `mirror.arvancloud.ir/ubuntu` دریافت می‌شوند. سایت فقط راهنما، کد ابزار و فراداده کوچک دارد. پوشه آماده‌شده روی دیسک **کامپیوتر خودتان یا حافظه قابل‌حمل** می‌ماند؛ این دستورها را روی سرور وب تهران نتورک اجرا نکنید.

## ۱. آماده‌سازی روی کامپیوتر متصل به اینترنت

Python 3، curl، gpgv، Ubuntu archive keyring و گواهی‌های TLS باید از قبل موجود باشند. در صورت نیاز، فقط روی کامپیوتر آماده‌ساز Ubuntu و با اینترنت:

```bash
sudo apt-get update
sudo apt-get install --no-install-recommends python3 curl gpgv ubuntu-keyring ca-certificates
```

زمان سیستم باید درست باشد. سپس بلوک زیر را کامل کپی کنید. پوشه `kit` باید جدید باشد؛ در صورت وجود، آن را بی‌دلیل پاک نکنید و ابتدا نسخه قبلی را نگه دارید. ابزار همه امضاها، نمایه‌ها و هش کامل بسته‌ها را بررسی می‌کند؛ خطا به معنی آماده‌نشدن بسته است.

```bash
(
set -euo pipefail
mkdir -p "$HOME/tehnet-offline"
cd "$HOME/tehnet-offline"
test ! -e kit
curl --proto '=https' --tlsv1.2 --fail --show-error --silent https://tehnet.ir/software/offline/offline_kit.py -o offline_kit.py
curl --proto '=https' --tlsv1.2 --fail --show-error --silent https://tehnet.ir/software/offline/profile.json -o profile.json
printf '%s  %s\n' 'fd35d9874932bc35fa8ff026c8608c61ed86533fc46d9ac56d00387e710e0fc9' offline_kit.py | sha256sum --check -
python3 offline_kit.py prepare --manifest profile.json --output kit
)
```

برای نسخه نخست، حدود ۶۰ مگابایت فایل به‌علاوه حاشیه آزاد و دست‌کم ۵۰۰ مگابایت فضای نصب لازم بود؛ برای نسخه جاری، اندازه‌ها و فضای بیشتر را در راهنمای سایت بررسی کنید. هر نسخه، بسته‌های دقیق خودش را ثابت نگه می‌دارد. فراداده `noble-updates` و `noble-security` هنگام آماده‌سازی حداکثر ۴۸ ساعت عمر دارند و تاریخ انقضا نیز بررسی می‌شود. سرویس خودکار هر ۶ ساعت بررسی می‌کند و پس از گذشت ۱۲ ساعت از آزمون موفق، پروفایل تازه را فقط پس از تأیید امضا و نصب پاک منتشر می‌کند. اگر میرور یا آزمون مشکل داشته باشد، نسخه قبلی می‌ماند و دریافتِ بیش از حد قدیمی عمداً رد می‌شود. ساعت را عقب نبرید و بررسی امضا/تاریخ را خاموش نکنید.

## ۲. انتقال و نصب بدون اینترنت

تمام پوشه `kit` را با ساختار داخلی‌اش به مسیر `$HOME/tehnet-offline/kit` روی اوبونتوی مقصد انتقال دهید. شبکه را قطع کنید و اجرا کنید:

```bash
cd "$HOME/tehnet-offline/kit"
sudo bash ./install.sh
```

اگر با کاربر root هستید، `sudo` را حذف کنید. نصب‌کننده فقط مخزن محلی پوشه را می‌خواند و دانلود را ممنوع می‌کند؛ تنظیمات مخازن معمول سیستم را تغییر نمی‌دهد. پیش از نصب، امضاها و هش‌ها را دوباره با APT اصلی Ubuntu بررسی می‌کند. نبود/خرابی فایل، امضای نامعتبر، نسخه جدیدترِ نصب‌شده یا حذف ناخواسته بسته‌ها باعث توقف پیش از تغییر وضعیت بسته‌ها می‌شود.

موفقیت با `OFFLINE_INSTALL_PASS` مشخص می‌شود. سپس:

```bash
git --version
curl --version
jq -nr '{answer:42}.answer'
python3.12 -c 'print(6 * 7)'
python3 -m pip --version
wget --version
rsync --version
ssh -V
sudo dpkg --audit
```

دو خروجی محاسبه باید `42` باشند و `dpkg --audit` خروجی نداشته باشد. نصب خود pip به معنی داشتن بسته‌های دلخواه PyPI یا wheelhouse آفلاین نیست. این بسته، ابزارهای توسعه و وابستگی‌های سیستم عاملِ آزموده‌شده را پوشش می‌دهد.

## محدوده و پشتیبانی

آزمون پذیرش روی Ubuntu Base 24.04.5 رسمی و پاک با معماری amd64 و شبکه جدا انجام می‌شود؛ این محیط یک ماشین مجازی بوت‌شده، همه ویرایش‌های دسکتاپ یا همه وضعیت‌های قدیمی/سفارشی سیستم نیست. ابزار از تنزل نسخه خودداری می‌کند. برای سیستم متفاوت، خطا را نگه دارید و پروفایل مناسب تهیه کنید؛ از `--allow-unauthenticated` یا اجبار تنزل نسخه استفاده نکنید.

نسخه‌های این پروفایل با دانلودهای تکی قدیمی سایت الزاماً یکسان نیستند؛ برای نصب آفلاین، کل پوشه همین پروفایل را استفاده کنید و بسته‌های نسخه‌های مختلف را ترکیب نکنید. دسترسی واقعی از شبکه ایران، تعرفه نیم‌بها و کارکرد میرور هنگام قطع اینترنت خارجی جداگانه تأیید نشده‌اند. روبیکا همچنان غیرفعال است و رمز بخش خصوصی را مالک روی سرور تعیین می‌کند.
