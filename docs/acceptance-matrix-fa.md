# ماتریس پذیرش مأموریت

مبنای ارزیابی: متن کامل `requirements-store-2026-10-15.fa.txt`. «آزموده محلی» به معنای انتشار یا پذیرش بانک/حمل/قانون نیست.

| خواسته | وضعیت مستند |
|---|---|
| مخزن واقعی و سایت | تأیید با remote، دسترسی GitHub، SSH، hash فایل و SQL read-only؛ شواهد در ops/audits |
| حفظ داده و drift | branch جدا از main، snapshot Core زنده، عدم استقرار یا حذف داده تولید |
| مقایسه راهکار بالغ | Woo/ERPNext/Odoo/Medusa/Saleor با مجوز و منابع رسمی؛ تصمیم Woo + ERPNext |
| تمام کاتالوگ | ۲۵ شناسه و ۱۲ دسته؛ draft بدون قیمت/stock واقعی یا تصویر بدون مجوز |
| اصلاح فنی دقیق | flag و منبع هر قلم ثبت؛ تطبیق مدل‌های متناقض و مدارک ادعای تست **در انتظار شواهد معتبر** |
| import تکرارپذیر/rollback | native WordPress، قفل، transaction، حفظ edit و soft-trash فقط run خود؛ آزموده |
| RTL/موبایل/جست‌وجو و فیلتر | آزموده محلی؛ فیلتر فنی فقط داده تأییدشده را می‌پذیرد |
| مقایسه/علاقه‌مندی | آزموده در مرورگر، persistence، Escape و safe DOM |
| رسانه/سه‌بعدی | گالری بومی آماده؛ تصویر جایگزین صریح؛ مدل/رسانه معتبر **فراهم نشده**؛ هیچ نمای جعلی ساخته نشد |
| سبد/آدرس/تخفیف | اجزای native Woo نصب؛ قیمت نهایی و رزرو سرور با ERP آزموده؛ جریان پرداخت واقعی بسته |
| پرداخت/برگشت بانکی | زرین‌پال انتخاب و پروتکل sandbox واقعی آزموده؛ آداپتور آزمایشی با 49 بررسی mock آماده و خاموش؛ خرید native کامل، credential تولید و برگشت بانکی **تأیید نشده** |
| حمل/اعلان | ثبت tracking و native Delivery Note آزموده؛ نرخ واقعی حمل و API/SMS/SMTP **متصل نشده** |
| حساب و فاکتور مشتری | native account، سند ERP چاپ‌پذیر، درخواست بررسی مرجوعی و کنترل مالکیت/nonce آزموده |
| انبار و COGS | ERP native، FIFO، reservation، Delivery Note/return؛ موجودی ساختگی آزموده، افتتاحیه واقعی **لازم است** |
| قرقره/متر | یک stock UOM متر و conversion در ERP؛ فروش/برگشت متری آزموده؛ طول واقعی هر مدل **تأیید لازم دارد** |
| خرید/انتقال/شمارش/بارکد | قابلیت native ERP و راهنمای عملیات؛ سناریوهای تجاری با پرسنل/اسکنر واقعی **آزموده نشده** |
| GL و تسویه | اسناد native، مبلغ صحیح IRR، replay، discount/shipping refund و fee settlement آزموده |
| مالیات/قانون/بستن دوره واقعی | قابلیت‌های native دوره و گزارش موجود؛ شرکت واقعی، سیاست‌ها و اتصال قانونی ایران **پیکربندی/تأیید نشده** |
| نقش و امنیت برنامه | چهار نقش عملیاتی، nonce، owner check، اسرار خارج Git و gateway بسته؛ آزمون نقش و HTTP 403 انجام شده |
| retry و پایش | outbox با replay ثابت، backoff محدود و status تطبیق؛ worker/alerting تولید **نیازمند استقرار تأییدشده** |
| backup و restore | بازیابی محلی SQL/files/key در هدف جدا آزموده؛ backup خارج میزبان، timer و restore تولید **شرط انتشارند و نصب نشده‌اند** |
| خرید کامل موبایلی | نمایش و حساب در موبایل آزموده؛ checkout با درگاه sandbox معتبر **هنوز اجرا نشده** |
| مستندات و ثبت Git | کد، تست، راهنمای فارسی مصور و شواهد این شاخه؛ هیچ داده خصوصی یا font binary در Git |
| GLM / مدل مدیر | یک مشاوره واقعی محدود GLM-5.3-Flash: ۷۰۷ ورودی + ۵۲۸ خروجی؛ مجری bulk در دسترس نیست. تغییر مدل/reasoning مدیر از ابزار تأیید نشده |

شرایط فعال‌سازی فروش: رفع flag هر محصول، قیمت و موجودی واقعی، انتخاب و آزمون adapterهای واقعی، پیکربندی مالیاتی/شرکت، ظرفیت و TLS/worker/backup معتبر و تأیید صریح انتشار. تا آن زمان نسخه محلی قابل بررسی است و ادعای «فروشگاه تولیدی کامل» ندارد.
