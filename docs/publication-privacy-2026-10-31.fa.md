# پاک‌سازی انتشار عمومی — ۳۱ اکتبر ۲۰۲۶

در این تاریخ GitHub مخزن TehNet را **عمومی** گزارش کرد. این تغییر، پاک‌سازی سورس و مستندات است؛ تغییر سرویس زنده، DNS، فایروال، پرداخت یا وضعیت noindex نیست.

## تغییر انجام‌شده

- IP واقعی Origin، IPv6 عملیاتی و آدرس داخلی preview از فایل‌های نسخهٔ جاری حذف/جایگزین شده‌اند. هدف deploy را از تنظیمات خصوصی اپراتور بگیرید.
- مسیر اختصاصی رایانه از گزارش‌ها حذف شده است. تست‌های مرورگر از نام استاندارد ماژول `playwright`/`sharp` استفاده می‌کنند؛ در فایل‌های دارای override، متغیر محیطی قبلی معتبر است. سایر اجراها می‌توانند `NODE_PATH` را خارج Git تنظیم کنند.
- گزارش تاریخیِ پاک‌سازی‌شده با گزارش اصلی یکسان نیست. آدرس‌های مستندسازی `192.0.2.0/24` و `2001:db8::/32` و علامت `[PRIVATE_LOCAL_PATH]` دادهٔ عملیاتی یا شاهد تست تازه نیستند. hashهای قدیمیِ این فایل‌ها دیگر گواه بایت‌های نسخهٔ پاک‌سازی‌شده نیستند؛ اصل خصوصی پیش از تغییر حفظ شده است.
- محافظ `tools/publication_guard.py` روی فایل‌های tracked، نوع فایل خصوصی، الگوهای credential، مسیر شخصی، credential داخل URL، آدرس صریح در اسناد عملیاتی و کلید خصوصی را بررسی می‌کند. خروجی آن فقط مسیر، شمارهٔ خط و دستهٔ ایراد است.
- استثناها دقیق و وابسته به hash محتوای نرمال‌شده به LF هستند: schema migration بدون داده، ورودی ساختگی تست ردِ URL و هویت TLS آزمایشگاهی که عمداً عمومی است. کلید fixture مجوز استفاده در تولید نیست؛ تغییر محتوا استثنا را باطل می‌کند.

## کنترل انتشار

```sh
python -m unittest discover -s tests -p test_publication_guard.py -v
python tools/publication_guard.py
gitleaks git . --redact=100 --log-opts=--all
```

محافظ محدود مکمل اسکنر تخصصی و بازبینی است، نه گواه نبود هر نوع secret. خروجی خام، backup، dump، فایل `.env` و اطلاعات مشتری را وارد Git نکنید. فقط نمونهٔ تنظیمات بدون مقدار واقعی و رسید پاک‌سازی‌شده منتشر شود. نشانی کسب‌وکار و راه تماس عمومیِ مورد تأیید مالک با اطلاعات ورود/Origin تفاوت دارد. CIDRهای عمومی Cloudflare و mirrorهای مجاز در منطق اعتبارسنجی حذف نشده‌اند.

## تاریخچه هنوز گیت جدا دارد

حذف از HEAD، commitهای قدیمی، شاخه‌های دیگر، PRها، forkها و cloneها را پاک نمی‌کند. اسکن Gitleaks همهٔ refهای محلی ۱۰۶ یافته داشت: یک هویت TLS عمداً عمومی و عمدتاً fingerprint امضای بسته/نام کلید و دادهٔ ساختگی؛ این عدد شمار credential فعال نیست. بررسی تاریخچه و نشانی‌های قدیمی جدا ثبت می‌شود. ادعای «ریپو کاملاً امن برای عمومی‌شدن» تا پایان پاک‌سازی تمام refها مجاز نیست.

طبق [راهنمای GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)، credential واقعیِ افشاشده باید revoke/rotate شود؛ بازنویسی سابقه نیازمند هماهنگی cloneها است و cached PR/fork ممکن است باقی بماند. هیچ rotation، force-push، حذف شاخه یا تغییر visibility در این مرحله اجرا نشده است. مقدار هیچ یافتهٔ حساس در گزارش عمومی ثبت نشود.

بازبینی دستی در مخزن خصوصیِ وابسته، یک رمز در متن تاریخی پیدا کرد که Gitleaks و نسخهٔ اول محافظ تشخیص نداده بودند. مقدار در گزارش عمومی منتقل نشده است؛ محافظ اکنون آزمون منفی ویژهٔ رمز در متن دارد. این یافته محدودیت اتکا به یک اسکنر را نشان می‌دهد. رسید تازهٔ [آزمون‌ها و تمرین سابقه](../qa/publication-2026-10-31/verification.json) فقط دامنهٔ نوشته‌شدهٔ خود را اثبات می‌کند؛ پاک‌سازی نسخهٔ آزمایشی، پاک‌سازی remote نیست.
