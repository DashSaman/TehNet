# اجرای راهنمای واقعی WinBox —۵نوامبر۲۰۲۶

مالک ادامهٔ مستقیم با آماده‌سازی مستقل لاب، تصاویر واقعی و سناریوی جدا برای هر قسمت را خواسته است. طرح PR79 مرجع است؛ مسیر قابل‌حمل QEMU/TCG برای سه CHR بدون driver/host adapter و با مدیریت loopback انتخاب شد. مسیر GNS3 فقط با VM رسمی و پس از پذیرش واقعی آن تکمیل می‌شود؛ اجرای محلیِ QEMU روی GNS3 Windows مسیر پشتیبانی‌شده فرض نمی‌شود.

- [x] دریافت رسمی/هش ناشر QEMU، 7-Zip، CHR و WinBox؛ استخراج بدون installer.
- [x] اجرای سه CHR نسخه۷٫۲۵٫۱، مدیریت loopback، restrict=on، LAN فقط socket داخلی؛ رابط مدیریت خارج Bridge.
- [x] ثبت۳۹تصویر اصلی WinBox۴٫۵؛ Safe Mode/Undo، Bridge، IP/DHCP واقعی، Backup/Export و restore واقعی، Snooping منفی/مثبت و ARP/MAC.
- [ ] تکمیل تصاویر باقی‌مانده و لاب GNS3؛ قابلیت انجام‌نشده با عکس ساختگی پر نشود.
- [ ] ساخت محتوای مرحله‌ای در مالکان موجود و callout نمایشی روی تصویرِ اصلی بدون تغییر پیکسل‌های آن؛ سناریو/زمان هدف جدا.
- [ ] آزمون native WordPress و مرورگر/RTL/mobile/no-JS، guard و commitهای محدود.
- [ ] انتشار فقط بستهٔ qualifyشده با backup/checksum/drift/rollback، سپس پذیرش مستقل زنده.

تصاویر فقط مقادیر ساخته‌شدهٔ لاب را دارند. دیسک، Backup، Export، رمزها، کلید SSH و گزارش خام بیرون Git می‌مانند. MyTel، noindex، پرداخت/ERP/CAPTCHA، داده‌های مشتری/۲۵محصول، خانه/منو و گیت‌های امنیتی دست‌نخورده‌اند. ضبط تازه‌ای ساخته نشده و بازبینی کامل ضبط‌های قدیمی همچنان جداست.


دستور مالک۵نوامبر: از این نقطه هیچ کلیک/تایپ/فعال‌کردن پنجره در دسکتاپ میزبان انجام نشود. WinBox اختصاصی این کار بسته شد؛ VMهای headless و کار کد/مرورگر headless ادامه دارند. تنظیمات برق/قفل/نمایشگر تغییر نکند. capture بعدی WinBox فقط از نمایشگر مهمان مستقل؛ با گذشت زمان مجوز تصرف مجدد دسکتاپ فرض نشود.
