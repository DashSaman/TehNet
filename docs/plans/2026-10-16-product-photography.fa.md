# عکس کاتالوگ و نمای ۳۶۰ — ۱۶ اکتبر ۲۰۲۶

مالکیت و اجازه استفاده تجاری از عکس‌های سعید شبکه در همین گفتگو توسط مالک تأیید شد. نسخه اصلی و واترمارک تعبیه‌شده دست‌نخورده می‌ماند؛ نشان کم‌رنگ tehnet.ir روی نمایش سایت افزوده می‌شود.

1. API عمومی هر ۲۵ شناسه و بایت‌های تصاویر دوباره دریافت و SHA256 و ابعاد ثبت شود. هر عکس فقط به همان شناسه منبع وصل شود؛ مدل سازنده از ظاهر عکس استنباط نشود.
2. واردسازی رسانه جدا از واردسازی کاتالوگ، با manifest و hash، پیش‌نمایش پیش‌فرض، کنترل مالکیت SKU/source، قفل، رسید و حفظ رسانه قبلی انجام شود. قیمت، موجودی، سفارش و خانه سایت تغییر نکنند.
3. عکس شاخص و گالری بومی Woo جایگزین SVG گروه کالا شوند. عکس منبع به معنی تأیید عکاسی واقعی، مدل، ابعاد یا اصالت نیست؛ تناقض‌های قبلی باز بمانند.
4. چرخان شماتیک برای کالای دارای عکس نمایش داده نشود. فقط توالی حداقل ۱۲ فریمِ بازبینی‌شده، متعلق به همان محصول، امکان چرخان عکس واقعی داشته باشد. یک یا دو عکس، نمای ۳۶۰ نیست.
5. تست PHP مستقل، lint، dry run واقعی، پشتیبان تولید، انتشار محدود، آزمون مرورگر و اجرای مجدد بدون تغییر؛ سپس مستندسازی و commit/push.

مرز شواهد: API منبع ۳۰ ردیف تصویر پس از حذف URL تکراری همان محصول دارد؛ در فهرست فعلی توالی ۳۶۰ موجود نیست. بعضی تصاویر نشانه‌های رندر/تصویرسازی و برچسب متناقض دارند؛ هیچ‌یک بدون مدرک «عکس واقعی موجودی تهران نتورک» نامیده نمی‌شود. نیاز به فریم‌های واقعی یا مدل معتبر برای تکمیل ۳۶۰ باقی است.

نتیجه: ۲۵ کالا/۳۰ ارجاع وارد و اجرای مجدد بدون تغییر تأیید شد؛ ۱۶ قرارداد نمایش، ۷ واردسازی، ۱۳ بررسی تصاویر تولید و ۱۴ بررسی عمومی تولید گذشتند. کنترل ۳۶۰ با توالی ساختگیِ جدا آزموده شد؛ هیچ فریم ساختگی وارد محصولات نشده است. هنگام بررسی تصویر تمام‌صفحه، honeypot قدیمی با left=-9999px باعث capture عریض ۱۰۳۷۱px در RTL بود. با clip داخل صفحه و حفظ input، عرض capture تازه ۳۹۰px شد. تغییر محدود CSS با backup فایل‌های قبل در انتشار `photo-layout` ثبت است.
