# مرحله بعد: پرداخت آزمایشی زرین‌پال

کاربر ادامه با انتخاب فنی مجری را مجاز کرده؛ استقرار و پرداخت واقعی همچنان ممنوع است.

انتخاب: پروتکل رسمی v4 زرین‌پال و فقط sandbox. نسخه رسمی Woo افزونه 5.1.1 بررسی می‌شود؛ به دلیل مسیر بازیابی code=101 و تبدیل ثابت مبلغ refund، فعال‌سازی بدون اصلاح برای این معماری انتخاب نمی‌شود. آداپتور کوچک آزمایشی جایگزین محصول بالغ تولیدی معرفی نمی‌شود.

1. ثبت منابع رسمی، نسخه و hash بسته؛ درخواست واقعی به sandbox بدون انتقال وجه.
2. آزمون منفی و مثبت برای مبلغ ریالی، اتصال authority به سفارش، callback تکراری، code=101، خطای ارتباط، سفارش بسته و محیط production.
3. آداپتور Woo خاموش به صورت پیش‌فرض؛ فقط local/staging، شرکت آزمایشی ERP و اقلام صریحاً synthetic. هیچ مسیر production، refund یا برداشت بانکی ندارد. اتصال کلاسیک و ثبت روش پرداخت Blocks طبق API رسمی؛ عبور خرید کامل هیچ‌کدام بدون آزمون native ادعا نمی‌شود.
4. دریافت server-to-server و receipt ماندگار قبل از payment_complete؛ انبار/GL همچنان در ERP آزمایشی. شکست یا نتیجه نامعلوم نیازمند تطبیق است، نه تراکنش جدید خودکار.
5. آزمون تازه، مستندات و commit. نتایج Docker قبلی و آزمون فعلی جدا؛ محدودیت named pipe محیط فعلی ثبت شود.
