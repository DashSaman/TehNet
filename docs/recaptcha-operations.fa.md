# کپچای فرم‌های تهران نتورک

اتصال Google reCAPTCHA v2 برای فرم خدمات، تیکت، استعلام محصول و درخواست پیش‌فاکتور در همان زیرساخت موجود پیاده‌سازی شده است. مسیرهای nonce، محدودیت تعداد درخواست و honeypot حفظ می‌شوند. هیچ سامانهٔ تیکت جدیدی ساخته نشده است.

وضعیت فعلی: **غیرفعال؛ کلید معتبر صادر نشده است**. تلاش واقعی کنسول Google برای دامنهٔ `tehnet.ir` با خطای سهمیهٔ ساخت پروژه متوقف شد؛ مسیر رسمی Cloud Console نیز محدودیت حساب به‌دلیل کشور/منطقه نشان داد. هیچ کلیدی ساخته نشد و پرداخت، افزایش سهمیه یا درخواست پشتیبانی ارسال نشد. نام/ایمیل حساب و جزئیات خصوصی در Git ثبت نمی‌شوند.

پس از دسترسی به حساب واجد شرایط، کلید v2 Checkbox مخصوص دامنه را در محل خصوصی خارج Git تنظیم کنید. روش ترجیحی ثابت‌های `TN_RECAPTCHA_SITE_KEY` و `TN_RECAPTCHA_SECRET_KEY` در پیکربندی خصوصی وردپرس است؛ `TN_RECAPTCHA_ENABLED` فقط پس از آزمایش واقعی باید `true` شود. گزینه‌های خصوصی `tn_recaptcha_site_key`، `tn_recaptcha_secret_key` و `tn_recaptcha_enabled=yes` نیز پشتیبانی می‌شوند؛ آن‌ها را non-autoload نگه دارید. مقدار کلید را در خط فرمان قابل ثبت، PR، لاگ، فایل محیط عمومی یا گفت‌وگو وارد نکنید. ثابت‌ها بر option مقدم‌اند.

در حالت غیرفعال، هیچ اسکریپت/درخواستی به Google اضافه نمی‌شود. در حالت فعال، خطای تنظیمات یا شبکه موجب رد درخواست می‌شود؛ مسیر تماس جایگزین نمایش داده می‌شود. اعتبارسنجی سمت سرور به پاسخ موفق Boolean، hostname دقیق همان سایت و زمان حداکثر۱۲۰ثانیه وابسته است. Google مصرف مجدد token را رد می‌کند. فرم‌ها token یا پاسخ خام Google را ذخیره نمی‌کنند؛ IP مشتری به Google فرستاده نمی‌شود.

آزمون‌های fixture، موفقیت واقعی ارائه‌دهنده نیستند. فعال‌سازی نیازمند آزمون با کلید واقعی در staging واجد مجوز، موبایل، چند فرم، خطا/انقضا، دسترسی شبکهٔ کاربران و تجربهٔ کاربران بدون JavaScript است. staging فعلی خروجی شبکه/ایمیل/پرداخت بسته دارد؛ برای آزمون قرارداد از پاسخ مصنوعی محدود و ثبت‌شده استفاده می‌شود. این پاسخ مصنوعی نباید وارد تولید شود.

منابع رسمی خوانده‌شده: [نمایش v2 و چند widget](https://developers.google.com/recaptcha/docs/display)، [اعتبارسنجی سمت سرور و انقضای token](https://developers.google.com/recaptcha/docs/verify). بدون کلید واقعی، این کار «اتصال آماده» است و نباید «حفاظت Google فعال» گزارش شود.
