# راهنمای مدیریت فروشگاه تهران نتورک — نسخهٔ مالک

به‌روزرسانی: ۲۷ اکتبر ۲۰۲۶. همهٔ مسیرها از منوی «عملیات فروشگاه» در پیشخوان وردپرس (`/wp-admin`) در دسترس‌اند.

## نقشهٔ پنل‌ها

| منو | چه کاری می‌کند |
|---|---|
| عملیات فروشگاه → عملیات | وضعیت سفارش‌ها + جستجوهای بی‌نتیجه (کالایی که مشتری می‌خواهد و ندارید) |
| → حسابداری | دفتر سفارش‌ها + پروفایل حقوقی (نام/شناسه/نشانی برای فاکتور) |
| → قیمت و نرخ ارز | پیش‌نمایش/اعمال گروهی قیمت = قیمت پایهٔ USD × نرخ (گرد به بالا به ۱۰۰۰ ریال) |
| → پرسش‌وپاسخ | تأیید پرسش‌ها + پاسخ → انتشار در صفحهٔ کالا |
| → هشدارها | هشدار قیمت/موجودی ثبت‌شدهٔ مشتریان + اجرای دستی بررسی |
| → سفارش سازمانی | درخواست‌های B2B: قیمت هر قلم + شماره پیش‌فاکتور + چاپ سند |
| → تیکت‌ها | پشتیبانی و استعلام‌های تک‌کالا (ارجاع = کد کالا) |

## کارهای روزمره

**۱. پاسخ به استعلام/تیکت:** تیکت‌ها → پاسخ را بنویسید → «ارسال پاسخ» (ذخیره + ایمیل مشتری وقتی SMTP تنظیم شود) → «بستن تیکت» پس از رفع.
**۲. صدور پیش‌فاکتور B2B:** سفارش سازمانی → در ردیف درخواست، قیمت ریالی هر قلم را وارد و «ذخیره قیمت‌ها و صدور» بزنید → شماره پیش‌فاکتور (مثل TN-PF-1405-0001) → «مشاهده/چاپ پیش‌فاکتور».
**۳. تغییر قیمت‌ها با نرخ ارز:** قیمت و نرخ ارز → نرخ (مثلاً 105000) → «پیش‌نمایش» → بررسی → «اعمال». شرط اول: در ویرایش هر کالا «قیمت پایه (USD)» پر شده باشد.
**۴. پاسخ پرسش کالا:** پرسش‌وپاسخ → پاسخ بنویسید → «ذخیره پاسخ و انتشار».
**۵. فاکتور مشتری:** سفارش پرداخت‌شده → حسابداری/فاکتور شماره‌دار (شمارهٔ محلی ترتیبی + تاریخ شمسی خودکار).

## سلامت و بکاپ (بدون دخالت شما)

- داشبورد سلامت عمومی: `https://tehnet.ir/tools/status` (وضعیت مسیرها/NTP/Redis/دیسک/آخرین بکاپ)
- بکاپ کامل شبانه ۰۰:۱۰ با تأیید یکپارچگی (سیستم‌تایمر `tehnet-store-backup`)؛ نگهداشت خودکار: ۴ نسخهٔ آخر + پاک‌سازی روزانه ۰۱:۰۰
- کش Redis فعال است؛ اگر بعد از بازسازی کانتینر وردپرس کش خاموش شود، سایت خودکار به کش داخلی برمی‌گردد (خطر قطعی نیست). راه اندازی مجدد: `docker exec tehnet-wordpress bash -c 'pecl install redis-6.1.0 && docker-php-ext-enable redis'` سپس ری‌استارت php

## چیزهایی که هنوز با شماست

مرچنت‌آیدی زرین‌پال • SMTP ایمیل • توکن تلگرام/VAPID/آروان • قیمت پایهٔ USD کالاها • پروفایل حقوقی • برند کالاها • عکس واقعی/MPN • مجوز indexing • رکورد time.tehnet.ir • و مهم‌تر از همه: **تعویض پسورد root سرور**.
