# Local release bundles and private diagnostics

Reviewed2026-11-01. This is local tooling acceptance, not a site deployment. See [dated evidence](../qa/growth-2026-10-31/bundle-path-diagnostics.json).

The reproduced Windows failure used a269-character lexical spelling with `..`, despite a235-character resolved destination. Normalize the new bundle destination before I/O and reject links first; never adopt an existing/partial package. [Microsoft](https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation) documents the relative-path limitation. [Python3.12](https://docs.python.org/3.12/library/pathlib.html#pathlib.Path.resolve) distinguishes an absolute spelling from resolving parent components/symlinks. No registry or OS setting changed.

Use the optional `--diagnostics-dir` with an existing absolute private directory outside repositories and WordPress roots. The CLI validates ancestor `.git`/`wp-config.php` markers, symlinks/junctions, restricted POSIX modes or Windows DACL/owner rules. The caller must still classify unusual or bare-repository roots; marker checks are not a universal filesystem classifier. Windows checks use the built-in .NET ACL API rather than depending on PowerShell module loading. Broad inherit-only grants are refused because new log files can inherit them. Do not loosen the private vault ACL to make a diagnostic pass.

On a failure, stdout contains only status, phase, exception class and whether private diagnostics were saved. Full exceptions and exact local paths stay in a newly named private log. If the destination fails validation or writing fails, the boolean remains false; the CLI does not expose the detail as a fallback. Native release logging remains separate. The optional directory is revalidated immediately before writing; this is not credential rotation or a general host-security certification.

An existing/partial package remains evidence. Diagnose the retained private output, choose a fresh destination after understanding the failure and validate immutable member/tool/runtime checksums. Do not delete a native journal, retry an unknown commit or replay a completed publication because local packaging failed. Bundle-only proof is not staging/apply/rollback qualification for a future content scope.
